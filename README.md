# Netflix Data Analysis

## Overview

This project analyzes Netflix's content catalog to uncover trends, patterns, and insights using data analytics techniques. The project covers data cleaning, transformation, exploratory data analysis (EDA), SQL analysis, and dashboard creation.

## Objectives

- Clean and preprocess the Netflix dataset.
- Handle missing values and duplicates.
- Perform exploratory data analysis (EDA).
- Analyze content trends and patterns.
- Identify popular genres and ratings.
- Explore country-wise content distribution.
- Create visualizations and dashboards.
- Generate meaningful business insights.

## Dataset

The dataset contains information about Netflix Movies and TV Shows, including:

- Show ID
- Type (Movie/TV Show)
- Title
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Genre
- Description

Source: Kaggle Netflix Titles Dataset

## Project Workflow

### 1. Data Cleaning
- Removed duplicate records.
- Handled missing values.
- Fixed data formatting issues.
- Converted date columns to datetime format.

### 2. Data Transformation
- Created new columns for analysis.
- Extracted year and month information.
- Prepared data for visualization.

### 3. Exploratory Data Analysis
- Movies vs TV Shows distribution.
- Top content-producing countries.
- Most common ratings.
- Popular genres.
- Content growth over time.
- Release year trends.

### 4. SQL Analysis
- Imported cleaned data into MySQL.
- Performed analytical queries.
- Validated insights using SQL.

### 5. Dashboard Creation
Built interactive Power BI dashboards to visualize:
- Content distribution
- Genre analysis
- Country analysis
- Rating analysis
- Year-wise trends

## Key Insights

- Movies make up the majority of Netflix content.
- Content production increased significantly after 2015.
- Drama and International Movies are among the most popular genres.
- The United States contributes the highest number of titles.
- TV Shows have grown steadily over recent years.
